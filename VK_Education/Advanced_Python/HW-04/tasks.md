# ЗАДАНИЕ

Это домашнее задание предназначено для получения практических навыков работы с файлами, регулярными выражениями, обработки массивов данных и создания слоёв кеширования. При реализации предполагается использование только базовых библиотек Python без использования внешних фреймворков.

Суть задачи заключается в разработке класса для работы с журналами событий (лог-файлами). Файлы хранятся в каталоге и именуются по правилу: `{{service_name}}_{{date}}.log`, где `date` — дата в формате `YYYYMMDDHH`. Каждый файл содержит события за определенный час, упорядоченные по времени.

Логи пишутся построчно в формате JSON. Поля объекта:
* `datetime`: дата события (соответствует часу из имени файла).
* `event_type`: уровень логирования (`ERROR`, `INFO`, `DEBUG`).
* `message`: текст сообщения.
* `params`: словарь для интерполяции переменных в текст сообщения вида `{"some_var": "some_value"}`.

В рамках этого домашнего задания необходимо реализовать класс, который принимает путь к папке с логами и предоставляет методы для анализа событий. Считаем, что новые файлы только появляются, а старые не меняются.

---

## Требования к коду

* Необходимо использовать стандартную библиотеку.
* Код должен соответствовать PEP 8.
* Запрещено возвращать `None` при ошибке, необходимо выбрасывать исключения.
* Допускается отсутствие строгих тайп хинтов, но их наличие приветствуется.

## Домашнее задание №4

### Шаг 1. Получение последних событий по сервису
**Задача:** Реализовать метод получения последних событий (аналог `tail -n`) для конкретного сервиса.

1. Создайте класс, описывающий событие. В тексте сообщения переменные из `params` должны быть уже интерполированы.
2. Реализуйте метод получения последних `N` событий по переданному имени сервиса.

### Шаг 2. Получение последних событий по всем сервисам
**Задача:** Реализовать методы получения последних событий в масштабе всей системы.

1. Реализуйте метод получения последних `N` событий суммарно по всем сервисам.
2. Реализуйте метод получения последних `N` событий по всем сервисам, в которых упоминается объект `X` (конкретное значение в словаре `params`).

### Шаг 3. Статистика ошибок и кеширование
**Задача:** Реализовать получение информации об ошибках (`event_type='ERROR'`) с использованием механизмов оптимизации.

1. Реализуйте метод получения количества ошибок в разрезе сервисов за переданный диапазон времени. **Важно:** задействуйте кеширование для ускорения повторных запросов.
2. Реализуйте метод получения даты последней ошибки по каждому сервису.
