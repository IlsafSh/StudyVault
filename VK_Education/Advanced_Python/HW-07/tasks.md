# ЗАДАНИЕ

Необходимо реализовать эффективное хранилище последних активных сессий пользователей таким образом, чтобы приложение корректно обрабатывало как удаление отдельных сессий, так и удаление всего хранилища. Главная цель — научиться управлять памятью в Python и избегать утечек.

В рамках этого домашнего задания необходимо выполнить 3 шага:
1. Реализовать хранилище сессий одного пользователя.
2. Создать кэш сессий пользователей с подсчётом попаданий.
3. Реализовать механизм автоматического завершения сессий при удалении менеджера.

---

## Требования к коду

* Необходимо использовать стандартную библиотеку.
* Код должен соответствовать PEP 8.
* Запрещено возвращать `None` при ошибке, необходимо выбрасывать пользовательские исключения.
* Допускается отсутствие строгих тайп хинтов, но их наличие приветствуется.

---

## Домашнее задание №7

### Шаг 1. Хранилище сессий одного пользователя
**Задача:** Создать класс `UserSessions`, который хранит набор последних сессий конкретного пользователя.

1. При добавлении сессии через `add_session` проверяйте, что `user_id` совпадает с идентификатором текущего хранилища. Если нет — выбрасывайте исключение `UnknownUser`.
2. Реализуйте метод `__len__`, возвращающий число активных сессий.
3. **Важно:** При удалении объектов сессий во внешнем коде, хранилище не должно удерживать на них ссылки (используйте механизмы управления памятью). После удаления всех сессий `len(self)` должен быть равен 0.

### Шаг 2. Кэш сессий пользователей
**Задача:** Реализовать класс `SessionsCache`, хранящий по одной последней сессии для каждого пользователя.

1. Метод `get_session(user_id)` должен возвращать сессию из кэша. Если её нет — создавать новую и сохранять в кэш.
2. Реализуйте свойство `hit_count` для подсчёта количества успешных извлечений сессий из кэша.
3. Реализуйте метод `__len__` для получения общего количества сессий в кэше.
4. **Важно:** При удалении сессий во внешнем коде кэш должен автоматически очищаться от соответствующих записей.

### Шаг 3. Научиться обрывать сессии
**Задача:** Реализовать класс `SessionManager`, который управляет жизненным циклом всех открытых сессий.

1. Метод `open_session(user_id)` создает новую сессию и регистрирует её в менеджере.
2. У сессии должен быть атрибут `logged_out`, который по умолчанию равен `None`.
3. **Важно:** При удалении экземпляра `SessionManager` (вызове деструктора) все связанные с ним сессии должны автоматически «оборваться» — значение `logged_out` должно быть установлено в `datetime.datetime.now()`.
